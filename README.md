# 生命歷程整理｜五欄事件時間軸

這是一個給台灣助人工作者使用的登入後生命歷程工具原型。v0.43 打開後直接顯示時間軸，首頁只保留必要的狀態、篩選與「新增事件」，並把每筆事件收斂為五個必要欄位：

1. 年度
2. 月份（未知可留空）
3. 事件人物
4. 事件大分類
5. 事件摘要

閱讀者先從時間軸辨識年月、人物與分類；只有點擊事件時，才會展開五欄摘要。畫面不再提供決策節點、影響、待釐清、信心、敏感度、起訖年、事件清單、檔案匯入與匯出等非本版目標功能。

## v0.43 使用流程

- 時間軸首頁：根網址與 `#tool` 都直接顯示概況、篩選與時間軸，不再先顯示入口頁或「開始整理」區塊。
- 低文字密度：移除宣傳標語、版本卡、重複操作說明與彈窗內的重複標題。
- 手動新增：按下「新增事件」才開啟五欄彈出視窗；儲存後回到時間軸並開啟該事件摘要。
- AI 協助整理：在同一個新增彈窗切換至「AI 協助整理」，可貼上文字或使用瀏覽器語音辨識，再整理成可編輯的五欄草稿。
- 語音輸入：辨識文字先出現在可編輯文字框，不會自動送出；停止後可修改，再按「整理成待確認草稿」。
- 人工確認：AI 或本機基本規則只產生草稿；每筆必須按下「確認加入時間軸」才會儲存。
- 事件編輯：從事件摘要按下「編輯這筆事件」，沿用同一個五欄彈出視窗並帶入原資料。
- 閱讀時間軸：以事件分類分列；事件按鈕只顯示月份與人物，點擊才看摘要。
- 橫向瀏覽：時間軸上方提供同步橫向捲動軌與前後按鈕，不必滾到圖表底部。

## 資料與相容性

- 新版事件儲存在瀏覽器 `localStorage` 的 `caseTimelineSimpleEvents:v1`。
- 舊版 `caseTimelineToolState` 只會被讀取並轉成五欄事件；原始舊資料不會被覆寫或刪除。
- 舊資料沒有月份時會保留「月份待確認」，不會自動猜測。
- 舊摘要依序沿用 `summary`、`fact`、`title`；舊人物關聯會轉成可閱讀的人物名稱。

## 資料與權限邊界

- AI 協助整理會呼叫同網域 `/api/analyze`；伺服器有設定 AI 供應商時，貼上的文字可能送至該供應商。使用前應先移除身分證、電話、地址等可識別資訊。
- API 未設定或不可用時，前端會改用本機基本規則產生草稿，介面會明確標示；本版不提供檔案匯入。
- 語音辨識使用瀏覽器提供的 Web Speech API，實際處理方式與支援度依瀏覽器而異；請勿說出身分證、電話或地址等可識別資訊。
- AI 與本機規則都不會自動把草稿加入時間軸，使用者需逐筆檢查五欄並確認。
- 本工具預期放在登入後工作區；目前 standalone 預覽本身尚未實作帳號驗證，不應單獨作為正式個案資料系統。

## 主要檔案

- `index.html`：時間軸首頁、手動／AI 協助新增 dialog、五欄草稿與事件摘要 dialog。
- `styles.css`：桌機與 390px 手機彈窗、頂部同步橫向控制、reduced-motion。
- `app.js`：五欄事件模型、舊資料遷移、語音轉寫、AI／本機辨識草稿、彈窗式新增／編輯與時間軸互動。
- `robots.txt`、`vercel.json`：測試階段 noindex 提示；noindex 不是存取控制。

## 本機啟動

```powershell
vercel dev --listen 127.0.0.1:4184
```
